# Sprint 3 — Linux Server Security Audit and Hardening

Audited the security posture of a Debian 12 server and applied configuration hardening. The work included reviewing open ports and active services, running checks with Lynis, AIDE, chkrootkit, rkhunter, and Nmap, and examining remote-access risks, user-account settings, and system services.

Audit results and evidence of the checks and changes are available in the report and the `artifacts/` directory.
