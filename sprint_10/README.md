# Sprint 10 — End-to-End DevSecOps for Spring PetClinic

Built an end-to-end DevSecOps workflow for Spring PetClinic, covering containerization, CI/CD, secret and dependency scanning, secure Kubernetes deployment, network policies, runtime monitoring with Falco, and admission control with Kyverno.

The project also includes an OWASP ZAP baseline scan and a Kubernetes security audit against the CIS Benchmark. Supporting manifests, rules, pipeline configuration, and reports are available in the repository.
