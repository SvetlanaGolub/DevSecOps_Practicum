**OWASP**

| Название | Почему важно | Что проверяем/метрика |
| ------ | ------ | ------ |
| Broken Access Control | Неавторизованный доступ к данным/админке | Права на ресурсы |
| Cryptographic Failures | Перехват/утечка данных, подмена | TLS, алгоритмы шифрования, хранение секретов | 
| Injection | Чтение/изменение БД, RCE | Неэкранированные вводы, конкатенация запросов | 
| Insecure Design | Отказ в обслуживании, злоупотребление бизнес-логикой/эскалация привилегий | Ограничения на частоту запросов, безопасные шаблоны |
| Security Misconfiguration | Захват админ-панели, утечки | Уязвимость эксплуатации (конфигурации)	Дефолтные пароли, открытые панели, лишние заголовки/плагины | 
| Vulnerable & Outdated Components | Эксплуатация известных уязвимостей | Реализация	Зависимость с известной уязвимостью (CVE), неподдерживаемые версии |
| Identification & Authentication Failures | Угон аккаунтов, эскалация прав | Слабые пароли, нет MFA, плохие сессии |
| Software & Data Integrity Failures | Supply‑chain атаки, внедрение кода | Проверка подписи артефактов, проверка целостности обновлений, SBOM и подписи контейнерных образов |
| Security Logging & Monitoring Failures | Позднее/невозможное обнаружение |  Нет журналирования аутентификаций и ошибок (логины/ошибки приложений) | 
| SSRF | Доступ к внутренним ресурсам | Проксирование пользовательских URL без валидации |
