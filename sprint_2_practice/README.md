# Sprint 2 Practice — DevSecOps CI/CD Fundamentals

Practiced documenting and automating foundational security checks in a GitLab CI/CD pipeline for a training project.

The repository includes the pipeline configuration (`.gitlab-ci.yml`), reference notes on OWASP and MITRE, RBAC documentation, a pipeline diagram, and screenshots showing successful and failed check runs. These materials illustrate how security checks can be integrated into CI/CD and how pipeline results can be reviewed.

## Key Materials

- [`docs/owasp_mitre.md`](docs/owasp_mitre.md) — OWASP and MITRE reference notes.
- [`docs/rbac.md`](docs/rbac.md) — notes on Role-Based Access Control (RBAC).
- [`docs/pipeline.puml`](docs/pipeline.puml) and [`docs/pipeline.png`](docs/pipeline.png) — pipeline diagram and rendered image.
- [`Test/`](Test/) — screenshots of check results.
- [`.gitlab-ci.yml`](.gitlab-ci.yml) — CI/CD pipeline configuration.
