# DevSecOps Practicum

A collection of hands-on security engineering exercises completed as part of a DevSecOps training program. The repository covers CI/CD security, application security testing, Linux and container hardening, Kubernetes security, threat modeling, and incident investigation.

## Sprint Overview

| Sprint | Focus |
|---|---|
| [Sprint 2](sprint_2/README.md) | CI/CD security testing for OWASP Juice Shop |
| [Sprint 2 Practice](sprint_2_practice/README.md) | Foundational security checks in GitLab CI/CD |
| [Sprint 3](sprint_3/README.md) | Linux server security audit and hardening |
| [Sprint 4](sprint_4/README.md) | Spring PetClinic container hardening |
| [Sprint 5](sprint_5/README.md) | Kubernetes security audit |
| [Sprint 7](sprint_7/README.md) | Application security testing |
| [Sprint 8](sprint_8/README.md) | Kubernetes incident investigation |
| [Sprint 9](sprint_9/README.md) | Threat modeling and risk assessment |
| [Sprint 10](sprint_10/README.md) | End-to-end DevSecOps for Spring PetClinic |

Each sprint directory contains a concise overview and, where available, a detailed `report.md` with implementation details and supporting evidence.

## Technologies and Tools

GitLab CI/CD, Docker, Kubernetes, Semgrep, Trivy, OWASP ZAP, Hadolint, Dockle, Grype, Lynis, AIDE, Nmap, Kubescape, DefectDojo, Falco, Kyverno, and OWASP Threat Dragon.

The repository documents practical exercises and their results. The scope and validation evidence for each task are described in the corresponding sprint documentation.
